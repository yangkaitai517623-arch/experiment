# 实验6运行说明

推荐在 `F:\web全栈实验` 打开终端，执行：
```
python -m http.server 8000 --bind 127.0.0.1
```
打开 `http://127.0.0.1:8000/实验6/代码/index.html`。

`代码/vendor` 已保存固定版本的 Vue 依赖，本地页面运行不需要访问CDN。直接双击HTML也可体验，但缓存与路由验证推荐使用上述HTTP方式。

实验5另有 `directives.html` 指令练习、`todos.html` TodoList。实验6另有 `Vite工程`：进入后运行 `npm ci`、`npm run dev`；构建用 `npm run build`。已安装环境可直接运行，提交包不包含node_modules。

留言和任务只保存到同源浏览器的localStorage，不会上传服务器。报告与运行截图存放于本实验或共用资料的对应子目录。
